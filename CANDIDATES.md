# Исключённые и неподтверждённые замечания

Эти пункты **не включены** в число 11 подтверждённых дефектов и не подготовлены к публикации как ошибки решения.

| Область | Наблюдение | Причина исключения |
|---|---|---|
| R08: нумерация с 1 на следующей паре | Воспроизведено: на второй паре новый студент получает место 1 при ожидающих с первой | Заказчик прямо ответил, что остаток не переносится на следующую пару, хотя его можно принять до конца дня. Это допускает отдельные очереди занятий; требование глобального FIFO между парами неоднозначно. Исключено из подтверждённых замечаний и из набора падающих регрессий. |
| Порт frontend в Docker Compose | 8080:80 при nginx listen 8080 | Та же конфигурация присутствует в базе eef98bb. Это унаследованная ошибка, не дефект данного PR. Docker daemon недоступен, запуск не воспроизводился. |
| ESLint | На HEAD 96 errors/2 warnings, в базе на том же инструменте 64 errors | Есть унаследованные и новые стилевые/статические замечания. Сами по себе они не доказывают нарушение рабочего сценария; build успешен. |
| Предупреждение build о TabList | Импорт из @mui/material не экспортируется, но не используется и сборка завершается | Нет воспроизведённого пользовательского сбоя. |
| Python 3.11 зависание из подготовительных записей | Упоминалось в AGENT_TASK | В нашем окружении полный прогон 973 тестов прошёл за 5.23 с; это не подтверждённый дефект. |
| Чётность недель ГУАП | Код использует ISO week parity, что может отличаться от академической | Найдены общие указания о старте с нечётной недели, но не установлено достаточное датированное основание именно для текущего семестра и конкретного live-источника. Нужна отдельная проверка первичного календаря, не публиковать как подтверждённое. |
| Docker-образ и schedules/ | backend.Dockerfile не копирует каталог расписаний в финальный образ | Есть риск отсутствия настроек при развёртывании без bind mount; из-за недоступного Docker runtime сценарий образа не исполнен. Оставлено вне подтверждённых находок. |
| Apps Script | Ожидает script_enabled и copy_lease; в backend не найдено описанное управление ими | Скрипт опционален, реальный Apps Script не запускался. Нет отдельного подтверждения влияния на обязательный lazy snapshot. |
| Совместная архивация backend/Apps Script | Межпроцессная аренда и гонки потенциально ненадёжны | Нет детерминированного воспроизведения двух реальных участников; гипотеза не считается дефектом. |
| Исчерпание квот Google Sheets | Чтение делает много запросов, кеш не выглядит включённым во все маршруты | Не измерена реальная нагрузка/квота и не воспроизведён пользовательский отказ на поддерживаемой конфигурации. |
| Сетевая ошибка после успешной записи | Возможны неоднозначные повторные действия | Не моделировался полный контракт частичного результата внешнего API; не публиковать без доказательства. |
| Идентификация через анкету | Cookie подписывает введённый логин без OAuth; это прямо оговорено авторами | Слабая идентификация заслуживает отдельного обсуждения, но обязательность нового OAuth в требованиях не установлена, старый поток регистрации тоже не проверяет владение логином. Не выдаётся за подтверждённое нарушение согласованного auth-контракта. |
| Однофамильцы/одинаковые ФИО и названия команд | Идентификация в хранилище по тексту может конфликтовать | Кандидат для отдельного воспроизведения, в нашем наборе такого сценария нет. |
| Многопроцессный backend | Локальный мьютекс не синхронизирует несколько workers | Авторы явно ограничили поддерживаемый режим одним процессом; поставляемый uvicorn запускается с одним worker. |
| Повторная защита уже успешно защищённой работы | ALREADY_PASSED запрещает её после истории | Заказчик разрешил новые защиты без ограничения числа за день, но не потребовал повторять уже успешно защищённую ту же работу; не делаем спорное замечание. |
| Ручное проставление результатов непосредственно в Sheets | Веб-экран read-only, авторы предлагают править статус в таблице | Наличие самого API/хранилища результатов признано. R10 относится именно к отсутствию вызова и состояния текущих защит, не утверждает, что результаты нельзя отметить вообще. |
| Аналитика истории | Нет отдельного веб-экрана аналитики | Аналитика не требовалась. Просмотр истории в Sheets сам по себе не объявляется дефектом. |

Формальные несоответствия путей ADR и отсутствующего перечня файлов в описании PR перечислены отдельно в REQUIREMENTS.md. По правилам зачёта они не подменяют падающий тест или воспроизводимое функциональное нарушение.
