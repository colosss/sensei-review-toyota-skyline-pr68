# Доказательства

`<ID>/` содержит инструкцию, команду, SHA и очищенное доказательство конкретной находки. Для автоматических регрессий run.log и result.json содержат реальный повторный результат после переноса структуры; exit code 1 означает ожидаемое падение на дефекте. Для ручных сценариев сохранены исходные наблюдения интерфейса и API, повторное выполнение при переносе не заявляется.

`baseline/` — общий первоначальный прогон, версии зависимостей, исходная фиксация UI и проверка закреплённого SHA отдельного checkout. Эти логи не являются успешным запуском на неинициализированном source текущего репозитория. Подробности — в REPORT.md.

Имена студентов синтетические; настоящих ключей и персональных данных нет. R08 исключён и остаётся в CANDIDATES.md.
