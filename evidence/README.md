# Доказательства

Храните небольшие очищенные логи и скриншоты по идентификатору находки. Укажите команду, SHA, версии окружения и exit code. Необработанные данные можно сохранять в игнорируемом `raw/`, но перед добавлением любых файлов проверьте отсутствие секретов и персональных данных.
