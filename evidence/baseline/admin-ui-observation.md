# Наблюдение интерфейса преподавателя

Проверена production-сборка закреплённого коммита в локальном браузере.
Вместо Google Sheets используются только синтетические записи Alice Synthetic и Bob Synthetic, группа G1, L1.
Существующий административный вход выполнен тестовой учётной записью.
Приложение отображалось через локальный маршрутизатор `/api/v1`, конфигурация VITE_API_BASE_URL=/api/v1.

Действия: `/admin` → вход → «Операционные системы» → «Очередь на сегодня».
Итоговый адрес: `/admin/courses/os-2026/queue`.

Наблюдаемый экран:

```text
Кнопка: Назад
Заголовок: Очередь на 2026-11-09
Кнопка: ОБНОВИТЬ
Таблица:
№ | Группа | Студент         | ЛР | Статус
1 | G1     | Alice Synthetic | L1 | ждёт
2 | G1     | Bob Synthetic   | L1 | ждёт
```

Кнопки вызова, смены результата и ручного открытия/закрытия записи на экране отсутствуют.
GitHub и время записи не отображаются.
Это наблюдение реального собранного интерфейса на подменённых внешних данных, а не проверка доступа к настоящей таблице.
Скриншот не сохранён; приведена текстовая фиксация дерева доступности браузера.
