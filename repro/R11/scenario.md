# R11: сценарий

1. Выберите курс с расписанием, в котором на сегодня для группы нет пары. Войдите преподавателем и откройте «Очередь на сегодня».
2. Попробуйте открыть запись для внештатного занятия: доступно только обновление списка; студент продолжает получать `403 QUEUE_CLOSED`.
3. На обычной открытой паре попробуйте досрочно закрыть новые записи: на экране также нет такого действия, решение об открытости берётся только из расписания.
4. Ожидаются ручные действия преподавателя, сохраняющие текущих ожидающих. Добавление/удаление слота или поправки в конфигурации изменяет запланированное расписание и не реализует отдельно оговорённое ручное открытие для занятия вне конфигурации.

Ожидается: Преподаватель открывает запись на незапланированное занятие либо прекращает новые записи до конца пары; ожидающие сохраняются.

Фактически: Запись определяется исключительно активной парой из YAML. На экране очереди нет управления открытием/закрытием; API или состояния ручного override также нет.
