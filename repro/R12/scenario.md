# R12: сценарий

1. Два студента с заполненными GitHub-логинами записываются на одну пару в разное время.
2. Откройте «Очередь на сегодня», затем соответствующий лист `Очередь-YYYY-MM-DD`.
3. В интерфейсе есть только №, группа, студент, ЛР, статус. В листе дополнительно есть номер пары, но нет GitHub и времени записи.
4. После архивирования в `История_очереди` добавляется лишь дата дня; точное время регистрации восстановить нельзя.
5. Ожидаются данные, прямо перечисленные заказчиком. Чтение актуального GitHub из листа группы не восстановит время попытки или прежний логин при изменениях.

Ожидается: Для каждой попытки доступны GitHub и фактическое время записи, в том числе после архивирования.

Фактически: Дневной лист хранит только позицию, группу, ФИО, ЛР, номер пары и статус; история добавляет только дату дня. GitHub и время записи нигде в модели попытки не сохраняются и не отображаются.
