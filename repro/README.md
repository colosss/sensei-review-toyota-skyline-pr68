# Воспроизведения

Для каждого дефекта создайте отдельный каталог с тестом/скриптом и README: SHA, версии зависимостей, синтетические данные, переменные окружения, точная команда запуска, ожидаемый и фактический вывод. Исходники приложения импортируйте из `source/`; не изменяйте приложение ради демонстрации.

Тестов пока нет. Не считайте отсутствие тестов успешной проверкой приложения.
