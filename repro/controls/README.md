# Положительные контрольные сценарии

Окружение и подготовка описаны в ../README.md. Из корня репозитория:

```bash
REVIEW_SOURCE="$PWD/source" .venv/bin/python -m pytest repro/controls/test_controls.py -q -p no:cacheprovider
```

Ожидается 9 passed, exit code 0. Проверяются нормальная запись/выход, настоящий провал CI, защита административного API, граница группы cookie, повторная запись после неявки, архивирование, поправки manual/guap к сохранённым слотам, конкурентная запись в одном процессе. Данные синтетические; реальные интеграции не проверяются.
